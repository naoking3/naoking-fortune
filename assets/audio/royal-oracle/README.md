# ROYAL ORACLE original audio

These sounds were created specifically for NAOKING KINGDOM. They use deterministic waveform synthesis from `tools/generate-royal-oracle-audio.mjs`; no external recording, game audio, anime audio, commercial library, or third-party sample is included.

- Source: original procedural synthesis
- Third-party license: none
- Attribution requirement: none
- Format: 24 kHz, mono, 16-bit PCM WAV
- Regeneration: run `node tools/generate-royal-oracle-audio.mjs`

The short mono format keeps browser transfer and decode cost modest while preserving the underwater bubbles, whistle, impacts, relay clicks, sonar, and metallic crown tones used by the scenes.
